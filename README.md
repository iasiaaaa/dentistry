Проєкт "WhiteLine"

Опис проєкту:
WhiteLine — це сучасний вебсайт для стоматологічної клініки, розроблений для зручного отримання інформації про послуги, команду лікарів, ціни та для онлайн-запису на прийом.

Основна мета проєкту — надати пацієнтам швидкий доступ до інформації, підвищити довіру до клініки через прозорість цін та відгуки, а також спростити процес запису на консультацію чи лікування.

Структура проєкту:
Проєкт має стандартну та логічну структуру для полегшення розробки та подальшої підтримки.

/dentistry/
|-- /images/           # Папка для всіх зображень
|   |-- 01.png, 02.png, 03.png, 04.png, 05.png, 06.png  # Номери послуг
|   |-- therapy.png, orthodontics.png, family.png        # Зображення послуг
|   |-- surgery.png, aesthetic.png, prosthetics.png
|   |-- team-1.png, team-2.png, team-3.png, ...         # Фото команди
|   |-- review-avatar-1.png, review-avatar-2.png, ...  # Аватари відгуків
|   |-- main.png, hero-background.png                   # Фонові зображення
|   |-- form-background.png                             # Фон форми
|   |-- Vector.png, Vector1.png, Vector2.png, Vector3.png  # Іконки
|-- index.html         # Головна сторінка (всі секції на одній сторінці)
|-- styles.css         # Файл стилів CSS
|-- README.md          # Документація проєкту

Особливості реалізації:
- Односторінковий додаток (SPA) з усіма секціями на одній сторінці
- Адаптивний дизайн для різних розмірів екранів (desktop, tablet, mobile)
- Мобільне меню з бургер-кнопкою для екранів менше 1024px
- JavaScript вбудований безпосередньо в HTML для керування мобільним меню
- Використання CSS Grid та Flexbox для гнучкого макету
- Сучасний дизайн з градієнтами, blur-ефектами та плавними переходами

Секції сайту:
1. Hero (Головна) - заголовок та основний опис клініки
2. Statistics (Статистика) - ключові показники клініки
3. Services (Послуги) - список послуг з описом та зображеннями
4. Team (Команда) - інформація про лікарів
5. Benefits (Переваги) - переваги клініки
6. Reviews (Відгуки) - відгуки пацієнтів
7. FAQ (Питання) - часто задавані питання
8. CTA Form (Форма запису) - форма для запису на прийом
9. Footer (Підвал) - контактна інформація та посилання

Технологічний стек:
Фронтенд: HTML5, CSS3, JavaScript (Vanilla JS)
Стилізація: CSS з використанням Flexbox, Grid, Media Queries
Шрифти: Google Fonts (Manrope, Inter)
